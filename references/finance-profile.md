# Finance Profile

## Visual identity

Institutional, restrained, modern, data-led. Reference the clarity of Bloomberg / WSJ / CNBC Explains without copying a specific brand system.

Use a layered visual grammar:

1. Background: industry B-roll or authentic report/filing imagery.
2. Readability layer: dark translucent overlay, gradient, or light blur.
3. Foreground: exact evidence — numbers, charts, labels, comparisons, report conclusions.

## Phase 1 pacing grammar

Use the semantic action that matches the editorial job: `verify` for authentic
reports and source regions, `accumulate` for institutions or evidence building
toward consensus, `causal` for mechanism explanations, `compare` for aligned
metrics or target prices, `turn` for a genuine change in interpretation, and
`conclude` or `pause` when the viewer needs to retain a judgment.

The motion budget should keep evidence ahead of context. After a dense evidence
or mechanism shot, prefer a readable hold or a simpler Visual Beat to release
cognitive pressure. This is pacing guidance, not a fixed number of seconds,
mandatory animation, or a quota for changing layouts.

## Editorial acceptance standard

This is **not a news package**. For context B-roll, **broad meaning is sufficient for context B-roll**: related industry footage is acceptable when
it supports the narration and is not labeled as a specific company facility,
customer, event, product, or location. Do not hold production for a literal
shot match.

Low-resolution report screenshots supplied by the user are accepted as visual
report backing. Keep them in the asset library and use them when helpful;
resolution is a presentation warning, not a rejection rule. If a screenshot is
too small to read, do not extract exact text from its pixels. Use verified text
or structured data for the exact foreground claim and keep the screenshot as
the report visual.

## Background coverage and material planning

For a finance video podcast with visible contextual footage, use 90% video-layer
coverage as the default target unless the user chooses another ratio. This is
the percentage of composition frames containing a valid background-video layer,
not the percentage of unique source footage. Pure data and exact evidence
holdouts are allowed when readability or source fidelity requires them.

Report both coverage and material sufficiency:

- measured video-background coverage;
- unique usable `keep` footage seconds;
- semantic categories and available alternates;
- reused clips or reused Shot IDs, with the number and treatment of repeats.

For a full-length composition, reuse existing assets when they remain broadly
relevant. Material quantity is not a production blocker: looping is allowed
when trims, crops, scale, speed, opacity, layout, or spacing make the reuse
editorially intentional. Report reuse separately from unique footage. Do not
turn a low unique-footage count into an automatic request for more material;
only flag a real gap when neither an existing asset nor a programmatic visual
can support the narration honestly.

Planning heuristics:

- 2.5-minute test: 4–8 minutes of usable footage across 4–6 semantic categories.
- 10-minute-plus program: roughly 20–30 minutes of usable footage and at least
  two distinct options for each recurring category.

These are planning baselines, not quotas and not a reason to pad the program or
block production. If the footage pool is small, record the reuse plan and use
related programmatic visuals for beats that need a different visual rhythm.

## Layer visibility

Coverage does not guarantee that the background can be perceived. Start with a
restrained dark institutional treatment and tune opacity by visual mode. A
useful starting band after readability overlays is approximately `0.22–0.42`:
lower beneath dense charts or report evidence, higher for section titles and
context-led moments. Verify both a still frame and a moving preview.

Avoid 10 minutes of the same left-side translucent card. Vary composition within one system: left/right panel, centered metric, horizontal flow, bottom data band, full-screen number, report paper, split comparison, three-column institution view.

## Evidence rules

Exactness required for:

- company/institution names
- ratings and target prices
- financial metrics and percentage changes
- valuation multiples/methods
- report claims
- dates/platform names
- report screenshot/page identity and provenance

Context B-roll may be approximate when it does not imply that the footage is the exact company, event, or facility. A screenshot's resolution does not determine whether it is accepted.

## Report evidence

When narration enters an institution section, prefer the authentic report cover/page as a background treatment: dim, slow push, gentle drift, optional blur. Foreground extracts the exact institution, target price, valuation method, and thesis.

Never fabricate a lookalike report page and present it as an authentic source.

## Finance visual modes

Prefer programmatic visuals for:

- target-price ranges
- revenue/profit metric cards
- gross-margin changes
- profit-quality bridges
- capex → equipment/factory → depreciation → profit-pressure flows
- PE / DCF / SOTP explanations
- peer regression
- TAM growth
- risk matrices
- FCF timelines
- institution comparison tables
